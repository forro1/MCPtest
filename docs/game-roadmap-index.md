# 卡牌 Rogue 游戏阶段路线图索引

本文档索引当前已确认的游戏架构阶段。每个阶段都有独立需求开发文档，后续开发应以对应阶段文档为准，避免把后续阶段内容提前塞进当前实现。

## 总体方向

游戏类型为卡牌 rogue。玩家扮演一代代从村庄出发的旅行者，与途中遇到的不同人或敌人进行牌桌对战。旅行者死亡后，下一任旅行者会继承村庄训练带来的小幅成长，并有机会在探索中找回前任留下的遗物、记忆碎片、卡牌、道具或牌桌能力。

主线分为两个阶段：

- 第一阶段：村庄不断派出旅行者探索生存空间，玩家逐渐理解牌桌、找回前任记忆，并最终击败表面 Boss。随后幕后 Boss 牌桌显现，通过时间回溯和洞悉弱点击败旅行者。若玩家牌桌未满足觉醒条件，旅行者死亡并回到第一阶段循环；若满足觉醒条件，玩家牌桌在致命一击前觉醒，旅行者返回村庄，第二阶段开启。
- 第二阶段：敌人开始拥有更强的牌桌规则能力，玩家围绕反制时间回溯、追查 Boss 牌桌来源、让自己的牌桌成熟展开冒险。最终击败 Boss 牌桌，获得时间回溯能力，并形成旅行者即最初老者的时间闭环。

## 开发原则

- 当前阶段只实现当前阶段必需内容。
- 所有系统优先形成可玩的闭环，再扩展内容数量。
- 村庄只承担轻量职责：记录、训练、研究、出发准备、剧情节点。
- 地图不是完全准确的客观地图，而是由前任旅行者、事件、村庄传闻和牌桌共鸣构成的半可靠情报。
- 牌桌能力必须成长，但不能复杂到压过卡牌战斗本身。首版优先使用少量被动、少量主动技能和统一轻资源。
- 每个阶段完成后都应更新对应文档的验收记录和后续 todo。
