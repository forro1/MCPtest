# 游戏总体设计文档

## 项目定位

本项目是一款卡牌 rogue 游戏。玩家扮演从村庄出发的一代代旅行者，通过牌桌与途中遇到的人和敌人进行战斗。每一任旅行者都可能死亡，但死亡不是简单失败读档，而是会留下记忆、遗物、卡牌、道具、牌桌能力和地图情报，成为后继旅行者继续探索的依据。

游戏核心体验是：

- 代际传承：一任旅行者的失败会改变下一任旅行者的目标。
- 不可靠探索：地图来自历代旅行者和村庄传闻，并不完全准确。
- 牌桌成长：牌桌从神秘被动规则逐渐成长为可主动协作的伙伴。
- 双阶段主线：玩家第一次接触真正的 Boss 牌桌后，游戏进入反制时间回溯的第二阶段。
- 时间闭环：最终旅行者获得时间回溯能力，发现自己就是最初赠予牌桌的老者。

## 核心故事

某个村庄为了探索生存空间，持续派出旅行者出游。临行前，一位老者赠送旅行者一个神奇牌桌。这个牌桌能让旅行者与敌人在牌桌上战斗，并为旅行者提供增益、对敌人施加削弱。

旅行者在探索中不断学习，击败敌人、找回前任旅行者的记忆，逐渐掌握更多卡牌技术和牌桌能力。每次旅行者死亡后，下一任旅行者会从村庄再次出发，并有机会找回前任留下的遗物。

第一阶段中，旅行者最终击败表面上的最终 Boss。幕后 Boss 随后显现，它并非普通敌人，而是 Boss 的牌桌。旅行者在即将击败它时，Boss 牌桌发动时间回溯，将战斗回到开始状态。此时 Boss 已洞悉旅行者弱点，并持续施加高额压制。若玩家牌桌没有满足觉醒条件，旅行者会被击杀并回到第一阶段循环。若满足觉醒条件，玩家牌桌会在致命一击前觉醒，抵挡攻击，旅行者返回村庄，第二阶段开启。

第二阶段中，敌人和世界都开始呈现更强的牌桌规则影响。玩家需要通过更复杂的策略、牌桌主动技能和反回溯准备，最终击败 Boss 牌桌。胜利后，玩家牌桌获得时间回溯能力。旅行者随后发现自己就是最初的老者，于是使用时间回溯，将牌桌带回最初并交给第一任旅行者，完成闭环。

## 核心循环

### 单局循环

1. 从村庄生成新任旅行者。
2. 选择出发准备和可用牌桌能力。
3. 查看村庄整理出的不可靠地图情报。
4. 选择路线和探索节点。
5. 触发战斗、事件、休息、前任回声或 Boss 节点。
6. 获得卡牌、道具、地图情报或牌桌成长。
7. 旅行者死亡、返回村庄，或推进阶段目标。
8. 将本局结果写回村庄长期状态。

### 代际循环

1. 当前旅行者死亡。
2. 系统记录死亡原因、死亡区域、携带物和重要经历。
3. 生成前任回声。
4. 村庄获得部分情报和训练成长。
5. 下一任旅行者从村庄出发。
6. 下一任旅行者在探索中可能发现前任回声。
7. 玩家选择立刻吸收回声，或带回村庄研究。

## 村庄定位

村庄是轻量的代际中枢，不做重度经营。

村庄职责：

- 记录历代旅行者。
- 保存地图情报和前任死亡线索。
- 提供小幅训练成长。
- 研究带回的遗物、记忆、卡牌和牌桌残片。
- 作为出发准备界面。
- 承载老者、村民、迁移和主线剧情节点。

村庄不承担：

- 人口管理。
- 建筑经营。
- 防御建设。
- 资源生产链。
- 大规模模拟经营。

## 地图与情报

地图不是完全准确的客观地图，而是由村庄根据历代旅行者的记录、事件、传闻和牌桌共鸣拼出的推测图。

地图情报状态：

- 未知：没有信息。
- 传闻：只知道大致方向或区域主题。
- 推测：知道可能节点类型，但有误差。
- 确认：当前旅行者亲自到达过，本局准确。
- 旧情报：前任确认过，但下一局可能偏移。
- 污染情报：受到时间回溯、Boss 或二阶段规则影响，可能误导。

不准确主要体现在：

- 奖励和风险不确定。
- 少量节点类型误判。
- 少量路线连接误差。

地图情报的价值不是让玩家完全消除迷雾，而是让玩家更有依据地承担风险。

## 前任回声与遗物

每个死亡旅行者都会留下前任回声。它可以表现为记忆碎片、遗物、卡牌、道具、牌桌能力或地图线索。

前任回声不固定在精确死亡坐标。因为村庄会迁移，旅行者出发位置也可能变化，世界还会受时间和牌桌规则影响。前任回声以特殊探索点形式出现，通常与死亡区域主题、死亡原因和携带物有关。

找到前任回声时，玩家需要选择：

- 立刻吸收：当前局获得直接强化。
- 带回村庄研究：当前局收益较小或延迟，但形成长期解锁。

这个选择是本游戏最重要的 rogue 决策之一。

## 卡牌战斗

战斗底座采用经典能量制卡牌战斗：

- 每回合抽牌。
- 每回合获得能量。
- 消耗能量打出卡牌。
- 卡牌产生伤害、格挡、治疗或其他效果。
- 敌人有行动或意图。
- 玩家通过构筑、出牌顺序和资源管理获胜。

当前 Unity 工程已具备基础卡牌战斗原型，包括 `CardData`、`EnemyData`、`StageData`、`BattleConfig`、`BattleState`、`DeckRuntime` 和 `TurnController`。

## 牌桌成长

牌桌早期以被动规则为主，后期逐渐出现主动技能。玩家牌桌本质上与旅行者同一阵营，旅行者在探索过程中逐渐掌握牌桌能力。

牌桌成长原则：

- 以技能树为骨架。
- 以遗物和事件作为关键突破。
- 以使用倾向作为轻微反馈。
- 每局只激活少量能力。
- 使用统一轻资源，例如共鸣值。
- 不引入复杂到压过卡牌战斗的第二套系统。

牌桌分支方向：

- 记忆：复制、保留、召回前任旅行者的卡牌或效果。
- 时间：回退抽牌、重掷奖励、延迟伤害，为最终时间回溯铺垫。
- 代价：用生命、弃牌、诅咒或风险换取强力效果。
- 共鸣：根据卡牌类型、连击、敌我状态触发额外规则。
- 压制：削弱敌人意图、限制敌人牌桌、改变敌人行动。

牌桌理解阶段：

1. 沉默：弱被动。
2. 回应：根据玩家行动触发规则。
3. 协作：玩家获得少量主动技能。
4. 觉醒：牌桌具备抵抗真 Boss 致命攻击和时间回溯的资格。

## 主线阶段

### 第一阶段

玩家持续派出旅行者，探索世界，找回前任记忆，扩展地图情报，培养牌桌。第一阶段目标是到达并击败表面 Boss，随后遭遇幕后 Boss 牌桌。

### 真 Boss 首遇

幕后 Boss 牌桌会在玩家接近胜利时使用时间回溯，将战斗回到开始状态。回溯后 Boss 洞悉旅行者弱点并施加高额压制。

若觉醒条件不足，旅行者死亡并回到第一阶段循环。

若觉醒条件满足，玩家牌桌觉醒，抵挡致命攻击，旅行者返回村庄，第二阶段开启。

觉醒条件为半明确、多路径、可失败重试。玩家知道方向是让牌桌理解旅行者并产生保护能力，但不需要按固定清单完成。

### 第二阶段

第二阶段是觉醒后的反制阶段。敌人开始拥有牌桌规则能力，地图情报出现污染，玩家需要通过更强策略和牌桌主动技能反制时间回溯。

二阶段敌人变化：

- 敌人拥有牌桌规则能力。
- 敌人轻度针对玩家构筑。
- 敌人叙事身份发生变化，出现规则污染、时间残影或觉醒形态。

### 终局

玩家最终击败 Boss 牌桌，获得时间回溯能力。随后发现自己就是最初赠予牌桌的老者，并将牌桌送回第一任旅行者手中，完成时间闭环。

## 首个可玩版本目标

首个可玩版本聚焦 Phase 1：代际循环验证。

首版验证三件事：

1. 死亡不是失败读档，而是生成下一任旅行者目标。
2. 地图不是确定信息，而是由前任旅行者留下的半可靠情报。
3. 前任遗物能形成当前局强化与村庄长期成长之间的取舍。

首版不做完整主线、完整二阶段、最终 Boss、时间回溯结局、重度村庄经营和完整牌桌技能树。
