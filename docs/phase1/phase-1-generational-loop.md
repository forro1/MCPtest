# Phase 1 - 代际循环验证需求开发文档

## 阶段目标

做出最小可玩的代际循环闭环，验证本游戏区别于普通卡牌 rogue 的核心体验：

村庄出发 -> 不可靠地图探索 -> 卡牌战斗 -> 旅行者死亡或结束 -> 留下前任回声 -> 下一任旅行者根据情报寻找回声 -> 选择当前局吸收或带回村庄研究。

本阶段不追求完整主线和二阶段，只验证死亡、记忆、遗物、地图情报和长期成长是否能形成有意义循环。

## 玩家体验目标

- 玩家能感受到死亡不是简单失败读档，而是会为下一任旅行者留下新目标。
- 玩家能看到地图情报不完全准确，需要根据风险和收益做判断。
- 玩家能在找到前任回声时做出有意义选择：立刻变强，或带回村庄长期研究。
- 玩家能连续经历至少两任旅行者，并看见前任行动对后任产生影响。

## 必做系统

### 村庄状态

- 保存历代旅行者记录。
- 保存基础训练等级。
- 保存已解锁卡牌或卡池标记。
- 保存已发现的地图情报。
- 保存已找回或待研究的遗物。

### 当前旅行者

- 新任旅行者从村庄状态生成。
- 初始数值受村庄训练小幅影响。
- 拥有当前生命、最大生命、牌组、遗物、牌桌能力和探索记录。
- 死亡时生成前任记录和前任回声。

### 不可靠地图

- 地图由若干节点组成。
- 节点显示的是情报，而不是完全准确事实。
- 情报至少包含疑似节点类型、风险等级、收益等级和可信度。
- 首版不需要复杂地图生成，可以使用小型固定模板加随机偏差。

### 探索节点

首版至少包含：

- 普通战斗
- 事件
- 休息或营地
- 前任回声
- 区域 Boss 或阶段终点

### 卡牌战斗

- 复用现有能量制卡牌战斗底座。
- 保留抽牌、能量、出牌、敌人行动、胜负结算。
- 加入一个简单牌桌被动能力。
- 加入一个简单牌桌主动技能，使用统一轻资源或固定冷却。

### 前任回声

- 旅行者死亡后，根据死亡区域、携带物和死亡原因生成回声。
- 下一任旅行者有机会在地图中遇到回声节点。
- 回声内容可包含记忆碎片、卡牌、道具或牌桌能力。
- 找到回声后提供两个选择：
  - 立刻吸收：当前局获得直接强化。
  - 带回村庄研究：当前局收益较小或延迟，但永久解锁长期成长。

### 长期成长

- 至少实现一种村庄训练成长，例如新任旅行者最大生命小幅提高。
- 至少实现一种研究解锁，例如某张卡牌进入奖励池或初始牌组候选。
- 长期成长必须轻量，不能让玩家通过死亡快速滚雪球。

## 暂不做内容

- 不做完整二阶段。
- 不做最终 Boss 和时间回溯剧情。
- 不做完整牌桌技能树。
- 不做重度村庄经营。
- 不做大规模程序化地图。
- 不做大量敌人和大量卡牌内容。

## 验收标准

- 玩家可以从村庄开始一局冒险。
- 玩家可以在不可靠地图上选择节点。
- 玩家可以进入至少一种战斗并完成胜负结算。
- 玩家死亡后会生成前任记录和前任回声。
- 下一任旅行者可以在地图中遇到前任回声。
- 玩家可以选择立刻吸收或带回村庄研究。
- 带回村庄研究会产生至少一种长期成长效果。
- 玩家连续两任旅行者后，能明确看到上一任失败影响了下一任目标。

## 风险点

- 地图不准确如果过强，会让玩家觉得被系统欺骗。
- 长期成长如果过强，会削弱 rogue 的单局策略。
- 前任回声如果只是奖励点，会失去叙事重量。
- 牌桌能力如果过早复杂化，会增加首版实现风险。

## 后续阶段依赖

- Phase 2 依赖本阶段的地图、旅行者记录和村庄状态。
- Phase 3 依赖本阶段的牌桌能力入口。
- Phase 4 依赖本阶段的前任回声和长期成长记录。

### 2026-07-03

- 已确认 Phase 1 先实现内存态循环，不实现本地存档介质。
- 已新增村庄长期状态、当前旅行者、地图情报、前任回声、牌桌成长入口、战斗适配层和 GameFlow 主流程。
- 已新增 Phase 1 原型 UI 入口。打开 `Assets/Scenes/SimpleCardBattle2D.unity` 并进入 Play Mode 后，默认显示村庄界面；如需回到旧单场战斗原型，可在 `SimpleCardBattle2D` 上关闭 `usePhaseOneLoop`。
- 战斗接入通过 `BattleFlowAdapter` 和 Phase 1 手动战斗面板复用 `TurnController` 和 `BattleState`，不重写现有卡牌战斗系统。
- 当前长期成长示例为：带回村庄研究后提升 `TrainingLevel`，后续旅行者最大生命随训练等级小幅提高。
- 当前立刻吸收示例为：当前旅行者最大生命和当前生命提高。
- 当前牌桌能力示例为：`memory_spark` 提供战斗开场格挡，`echo_call` 提供战斗开场额外能量。
- 探索节点会记录到当前旅行者确认情报和村庄地图情报中，供后续代际循环扩展。
- 当前 UI 为最小可验证原型，不代表最终视觉风格。
