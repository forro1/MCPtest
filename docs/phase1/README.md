# Phase 1 文档索引

Phase 1 目标是验证代际循环最小闭环：村庄出发、不可靠地图、基础战斗、旅行者死亡、前任回声、下一任找回遗物，并在当前局吸收或带回村庄研究。

## 使用方式

正式开发前先阅读需求开发文档和详细设计文档。进入开发时以开发任务清单为执行参照，并用测试与验收文档记录验证结果。
