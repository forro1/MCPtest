# Phase 2 - 第一阶段冒险扩展需求开发文档

## 阶段目标

在 Phase 1 的代际循环闭环基础上，扩展第一阶段冒险内容，使玩家能体验一段较完整的村庄外出探索流程。

本阶段重点是丰富地图、敌人、事件、路线选择和村庄轻量成长，不进入真正的二阶段，也不实现最终时间闭环。

## 玩家体验目标

- 玩家能在多局冒险中感受到不同区域、不同路线和不同敌人组合。
- 玩家能通过前任情报和村庄记录，做出更有依据但仍不完全确定的路线选择。
- 玩家能看到村庄训练、研究、地图记录持续改善后续旅行者的开局条件。
- 玩家能逐渐理解表面 Boss 的存在，并朝第一阶段终点推进。

## 必做系统

### 区域主题

至少扩展 2-3 个区域主题，例如：

- 森林边境
- 废弃村道
- 雾地沼泽

每个区域应有自己的敌人倾向、事件类型、情报可靠度和奖励倾向。

### 地图情报成长

- 地图情报不是完全揭示地图，而是提升可信度。
- 同一区域被多任旅行者探索后，村庄对其风险、收益、节点类型的判断更稳定。
- 靠近 Boss 或特殊污染区域时，情报仍可能失真。

### 事件系统

加入可复用事件结构。事件应能产生：

- 当前局收益
- 长期村庄收益
- 前任回声线索
- 牌桌成长线索
- 地图情报修正

### 敌人与奖励扩展

- 增加基础敌人数量。
- 增加至少一个精英敌人。
- 增加更多卡牌奖励。
- 增加若干道具或遗物。

### 表面 Boss 路线

- 加入第一阶段表面 Boss 的早期雏形。
- 玩家暂时不需要进入真 Boss 牌桌剧情，但应能感受到主线终点正在接近。

### 村庄轻量职责

村庄只做轻量系统：

- 查看历代旅行者记录。
- 查看已知地图情报。
- 进行训练升级。
- 研究带回的遗物。
- 选择下一任旅行者的出发准备。

## 暂不做内容

- 不做二阶段敌人规则升级。
- 不做真 Boss 牌桌的时间回溯战斗。
- 不做完整技能树，只保留牌桌成长预留接口或少量分支雏形。
- 不做村庄人口、建筑、防御、资源生产等重经营。

## 验收标准

- 玩家可以在至少 2 个区域之间或区域内路线之间做选择。
- 地图情报会随着历代旅行者探索而变化，但不会变成完全确定。
- 玩家能遇到普通战斗、事件、休息、前任回声、精英或 Boss 相关节点。
- 村庄记录能反映前几任旅行者探索过的区域和死亡线索。
- 玩家能完成一段第一阶段冒险，并到达表面 Boss 路线或其前置节点。

## 风险点

- 内容扩展容易掩盖核心循环问题，应先保证 Phase 1 闭环稳定。
- 地图情报成长如果过于数值化，会失去探索神秘感。
- 区域差异如果只体现在敌人数值，会显得平。

## 后续阶段依赖

- Phase 3 需要本阶段提供足够事件和奖励入口来承载牌桌成长。
- Phase 4 需要本阶段提供表面 Boss 路线和第一阶段终点。
- Phase 5 会复用本阶段区域，并在二阶段加入规则污染和叙事反转。
